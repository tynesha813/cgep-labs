\# CGEP GRC Engineering Labs



Hands-on GRC engineering portfolio focused on translating governance, risk, and compliance requirements into technical controls, policy-as-code, automated testing, and machine-readable evidence.



\## Lab Portfolio



\### Lab 2.3 — Compliant AWS S3 Primitive



Built and deployed an AWS S3 architecture using Terraform with controls mapped to NIST 800-53 requirements.



Implemented:



\- Encryption at rest

\- Public access prevention

\- Versioning

\- Centralized access logging

\- Standardized compliance metadata

\- Machine-readable Terraform evidence



\*\*Technologies:\*\* AWS, Terraform, AWS CLI, Git



Additional labs will extend this repository with reusable Terraform modules, automation, policy-as-code, and evidence-integrity capabilities.
